# martinativadar.github.io

Personal GitHub Pages site for technical writing about vulnerability research
and data science.

## Local Preview

Open `index.html` in a browser, or serve the folder locally:

```sh
python3 -m http.server 4000
```

Then visit `http://localhost:4000`.

## Publishing

This repository is ready for GitHub Pages. In the GitHub repository settings,
enable Pages for the default branch and use the repository root as the source.
